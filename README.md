# 包学堂 · 箱包行业知识库

一个无需安装依赖的中文箱包行业学习网站，包含材料、结构、工艺、质量、日语术语和日本客户实务案例六大模块。

## 本地查看

直接双击 `index.html` 即可，或在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 功能

- 六大知识模块与可逐级浏览的详细词条
- 支持中文、日文、假名和解释内容的实时搜索
- 可点击的分类卡片、标签、学习路径与面包屑导航
- 日语四栏术语表、实务案例和本地持久化学习笔记
- 响应式布局，支持电脑与手机
